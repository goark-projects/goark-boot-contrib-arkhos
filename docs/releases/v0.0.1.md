# Goark Boot Contrib Arkhos 0.0.1

English | [中文](https://github.com/goark-projects/goark-boot-contrib-arkhos/blob/v0.0.1/docs/releases/v0.0.1.zh-CN.md)

Release date: September 7, 2026

Goark Boot Contrib Arkhos 0.0.1 is the first public embedded-container Starter.
It owns Arkhos creation, server startup, readiness, logging integration, and
ordered shutdown without hiding the container behind runtime scanning.

See the [changelog](https://github.com/goark-projects/goark-boot-contrib-arkhos/blob/v0.0.1/CHANGELOG.md#001---2026-09-07)
for the concise version history.

## :star: New Features

- Auto-configure the default Hertz-backed Arkhos container.
- Allow applications to replace the container provider explicitly.
- Map addresses, timeouts, request limits, and async behavior from Boot
  configuration with startup validation.
- Route Hertz diagnostics through the Goark logging lifecycle.

## :package: Installation

```bash
go get goark.dev/gbc-arkhos@v0.0.1
```

Go 1.26 or later is required. The release consumes Arkarta 0.0.3, Arkhos
0.0.1, Goark Core 0.0.1, Boot 0.0.1, goark-log 0.0.3, and gbc-log 0.0.1.

## :white_check_mark: Verification

The candidate passed tests, vet, race tests, readiness, shutdown, validation,
and logging integration on Windows Go 1.26 and Debian Linux Go 1.27.
