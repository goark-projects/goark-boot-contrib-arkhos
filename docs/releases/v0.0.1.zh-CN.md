# Goark Boot Contrib Arkhos 0.0.1

[English](https://github.com/goark-projects/goark-boot-contrib-arkhos/blob/v0.0.1/docs/releases/v0.0.1.md) | 中文

发布日期：2026 年 9 月 6 日

Goark Boot Contrib Arkhos 0.0.1 是首个公开的嵌入式容器 Starter。它负责 Arkhos
创建、Server 启动、就绪状态、日志集成和有序关闭，不使用运行时扫描隐藏容器。

精简版本历史见[变更日志](https://github.com/goark-projects/goark-boot-contrib-arkhos/blob/v0.0.1/CHANGELOG.zh-CN.md#001---2026-09-07)。

## :star: 新功能

- 自动配置默认的 Hertz Arkhos 容器。
- 允许应用显式替换容器 Provider。
- 从 Boot 配置映射地址、超时、请求限制和异步行为，并在启动前校验。
- 将 Hertz 诊断日志接入 Goark 日志生命周期。

## :package: 安装

```bash
go get goark.dev/gbc-arkhos@v0.0.1
```

要求 Go 1.26 或更高版本。本版本依赖 Arkarta 0.0.3、Arkhos 0.0.1、Goark Core
0.0.1、Boot 0.0.1、goark-log 0.0.3 和 gbc-log 0.0.1。

## :white_check_mark: 验证

候选版本已在 Windows Go 1.26 和 Debian Linux Go 1.27 上通过测试、vet、race、
就绪状态、关闭、配置校验和日志集成。
